### 重要简化决策

**eBPF事件采集简化**：暂时只保留进程事件，移除文件事件和网络事件。

| 事件类型 | 状态 | 说明 |
|:---|:---|:---|
| process_exec | ✅ 保留 | 进程执行 |
| process_fork | ✅ 保留 | 进程创建 |
| process_exit | ✅ 保留 | 进程退出 |
| file_access | ❌ 移除 | 规则主要基于进程判定 |
| network_connect | ❌ 移除 | 规则主要基于进程判定 |
| privilege_change | ❌ 移除 | 规则主要基于进程判定 |

**原因**：
1. 现有规则主要基于进程行为判定
2. 减少事件量，降低系统负载
3. 简化实现复杂度

## 二、架构设计

### 2.1 告警状态流转

```
告警生成 → 待处置
              ↓
         用户点击处置 → 已处置
              ↓
         用户点击阻断 → 阻断中
              ↓
         Agent执行阻断
              ├─ 成功 → 阻断成功
              └─ 失败 → 阻断失败（显示原因）
```

### 2.2 告警来源标记

| 来源 | 标记 | 说明 |
|:---|:---|:---|
| Sigma规则命中 | 系统判定 | 规则直接匹配 |
| LLM分析确认 | AI判定 | LLM聚合后确认异常 |
| LLM自动处置 | AI判定+自动处置 | 开启自动处置时执行 |

### 2.3 LLM聚合流程变更

**旧流程**（自动2分钟聚合）:
```
事件上报 → 2分钟窗口聚合 → 自动LLM分析 → 生成告警
```

**新流程**（手动按时间筛选）:
```
事件上报 → 存储原始事件（临时表）
用户选择时间范围 → 手动触发聚合 → LLM分析 → 
  ├─ 异常事件 → 标记AI判定 + 生成告警/自动处置
  └─ 正常事件 → 标记系统判定（或过滤）
```

### 2.4 阻断动作扩展

| 动作 | 参数 | 说明 | 实现状态 |
|:---|:---|:---|:---|
| kill_process | pid | 杀死进程 | ✅ 已实现 |
| quarantine_file | file_path | 隔离文件 | ✅ 已实现 |
| block_connection | remote_addr | 阻断网络 | ✅ 已实现 |
| disable_user | username | 禁用用户 | ✅ 已实现 |
| revoke_permission | file_path | 撤销权限 | ✅ 已实现 |
| **isolate_file** | file_path | 文件隔离（新增到策略选项） | 需暴露给策略 |

```go
// 移除file_access、network_connect、privilege_change事件加载
// 只保留:
// - process_exec (sched_process_exec)
// - process_fork (sched_process_fork)  
// - process_exit (sched_process_exit)

func (l *EBPFLoader) LoadAll() error {
    // 只加载进程相关程序
    if err := l.LoadProgram("execve", execveSpec); err != nil {
        return err
    }
    if err := l.LoadProgram("fork", forkSpec); err != nil {
        return err
    }
    if err := l.LoadProgram("exit", exitSpec); err != nil {
        return err
    }
    // 不再加载: openat, connect, setuid, setgid, capset
    return nil
}
```

```go
var sensitivePaths = []string{
    "/etc/shadow",
    "/etc/passwd", 
    "/root/.ssh",
    "/var/lib/postgresql",
    // ... 其他敏感目录
}

// ReadFileContent 读取文件内容（限制大小，禁止敏感目录）
func (t *FileTools) ReadFileContent(filePath string, maxSize int64) (*FileContent, error) {
    // 检查是否在敏感目录
    if t.isSensitivePath(filePath) {
        return nil, fmt.Errorf("access denied: sensitive path")
    }
    // 检查文件大小
    info, err := os.Stat(filePath)
    if err != nil {
        return nil, err
    }
    if info.Size() > maxSize {
        // 只读取前maxSize字节
    }
    // 读取内容并返回
}

func (t *FileTools) isSensitivePath(path string) bool {
    absPath, _ := filepath.Abs(path)
    for _, sp := range sensitivePaths {
        if strings.HasPrefix(absPath, sp) {
            return true
        }
    }
    return false
}
```
**测试**: 通过gRPC调用工具验证，敏感目录返回权限拒绝
