## 1. 产品概述

### 1.1 产品定位

Aegis智能主机安全系统是一个面向企业级运维和安全团队的全方位主机安全管理平台。系统融合大语言模型（LLM）的智能分析能力与Agent的自动化执行能力，实现从基线合规检查到漏洞智能修复再到运行时异常检测的完整安全运营闭环。

### 1.2 核心价值主张

| 功能模块 | 核心价值 |
|----------|----------|
| 智能基线管理 | 自动化解析安全基线文档，生成可执行检查脚本 |
| 漏洞智能修复 | 一键扫描软件漏洞，LLM生成精准修复方案 |
| 运行时异常检测 | eBPF实时采集 + Sigma规则匹配 + LLM智能研判 |
| 自动阻断处置 | 支持自动阻断、自动处置，实时响应威胁 |
| 智能误报检测 | 自动检测高频规则，LLM分析并加严规则 |
| AI规则生成 | 描述检测事件，LLM自动生成Sigma规则 |
| 全中文界面 | MITRE中文映射，符合国内用户习惯 |

### 1.3 目标用户

| 用户角色 | 核心需求 | 使用场景 |
|----------|----------|----------|
| 系统管理员 | 主机资产管理、合规检查 | 批量主机纳管、定期基线检查 |
| 运维工程师 | 自动化运维、故障修复 | 漏洞修复、配置修复 |
| 安全工程师 | 漏洞管理、安全合规、运行时检测 | 漏洞扫描、异常检测、阻断处理 |
| 安全合规专员 | 合规审计、报告生成 | 基线合规审计、漏洞报告 |

## 4. 智能误报检测（后台服务）

### 4.1 功能描述

后台自动检测规则触发频率，当满足阈值时调用LLM分析是否为误报，并自动加严规则。

### 4.2 检测阈值

| 时间窗口 | 阈值 | 触发动作 |
|---------|------|---------|
| 10分钟 | >10条 | 调用LLM分析 |
| 30分钟 | >30条 | 调用LLM分析 |
| 1小时 | >60条 | 调用LLM分析 |

### 4.3 处理流程

```
定时检测（10m/30m/60m）
    ↓
统计规则触发数
    ↓
超过阈值 → LLM分析
    ↓
确认误报（置信度>=0.7）→ 加严规则
    ↓
状态设为 experimental
    ↓
保存到数据库（暂不下发Agent）
    ↓
┌─────────────────────────────┐
│  1小时观察期                │
│  - 用户可在页面查看并禁用   │
└─────────────────────────────┘
    ↓ 无人禁用
自动升级为 active
    ↓
广播下发到Agent
```

### 4.4 规则加严策略

| 加严方式 | 说明 |
|---------|------|
| 添加条件 | 增加更严格的匹配条件 |
| 排除模式 | 排除已知误报场景 |
| 阈值调整 | 提高触发阈值 |

## 5. MITRE ID规范

### 5.1 格式规范

- **统一格式**: 大写T开头，如 `T1059.004`
- **数据库约束**: `UNIQUE (mitre_id)`
- **数据一致性**: 规则、阻断策略、告警三表MITRE ID格式一致

### 5.2 唯一性约束

- 创建规则时检查MITRE ID是否已存在
- 存在则返回400错误，不允许重复

### 5.3 数据关联

| 数据类型 | MITRE ID来源 |
|---------|-------------|
| 规则 | Sigma规则YAML解析或用户指定 |
| 阻断策略 | 关联规则的MITRE ID，1对1对应 |
| 告警 | 继承触发规则的MITRE ID |

## 7. 数据模型

### 7.1 Alert（告警）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | UUID | 主键 |
| `alert_id` | String | 告警ID（ALT-xxx） |
| `host_id` | UUID | 主机ID |
| `mitre_id` | String | MITRE技术编号（大写T格式） |
| `mitre_name` | String | MITRE中文名称 |
| `rule_id` | String | 关联规则ID |
| `rule_title` | String | 规则标题 |
| `severity` | String | 严重程度 |
| `status` | String | 状态（pending/resolved） |
| `description` | Text | 中文描述 |
| `hit_count` | Int | 命中次数 |
| `judgment_source` | String | 判定来源（system/ai） |
