# Aegis V6.1 弱密码检测前端页面 PRD

## 1. 文档目标

本文定义 V6.1 弱密码检测能力的前端页面需求，覆盖页面入口、信息架构、核心流程、交互状态、字段展示、权限审计和前端测试。本文只描述前端产品和交互，不描述后端具体实现细节；后端接口和数据表分别见 `weak_password_api_server_design_v6.1.md` 和 `weak_password_database_design_v6.1.md`。

## 2. 用户目标

安全运营人员需要在页面中完成以下闭环：

1. 一键分析资产中的应用资产。
2. 查看所有可能存在密码的应用。
3. 对单个应用发起弱密码检查。
4. 查看 Agent 获取配置、AI 修复定位、密码匹配和结果入库进度。
5. 管理默认 1000 条弱密码字典、上传字典和 AI 生成字典。
6. 查看命中弱密码、失败原因、AI 解释和整改建议。

## 3. 页面入口和路由

建议新增路由：

| 路由 | 页面 | 说明 |
|:---|:---|:---|
| `/risk/weak-password` | 弱密码检测首页 | 默认进入应用资产分析 Tab |
| `/risk/weak-password/tasks/:id` | 弱密码任务详情 | 展示进度、主机、应用、结果和错误 |
| `/risk/weak-password/dictionaries` | 字典管理 | 默认 1000 字典、上传字典、AI 生成字典 |

| `frontend/src/views/detection/WeakPassword/Index.vue` | 弱密码检测首页 |

## 4. 信息架构

弱密码检测首页包含 4 个 Tab：

| Tab | 目标 | 默认展示 |
|:---|:---|:---|
| 应用资产分析 | 一键分析应用资产，列出可能存在密码的应用 | 默认 Tab |
| 弱密码检查 | 查看进行中的检查任务和创建检查 | 次级 Tab |
| 字典管理 | 管理默认字典、上传字典、AI 生成字典 | 可跳转独立页面 |
| 检测结果 | 查看命中、失败、AI 解释和整改建议 | 支持筛选 |

页面整体不做营销式介绍，不使用大幅 hero。弱密码检测属于安全运营工作台，应采用紧凑、可扫描、信息密度较高的布局。

## 5. 应用资产分析页

### 5.1 页面目标

用户点击“一键分析资产应用”后，系统只分析资产采集结果中的应用资产，不扫描主机文件系统，不调用 Agent 读取文件。分析结果是“可能存在密码的应用列表”，用于后续单应用弱密码检查。

### 5.2 空资产状态

当当前筛选范围没有应用资产时，显示空状态：

- 标题：暂无可分析的应用资产。
- 说明：请先执行资产采集，系统将基于采集到的应用资产分析可能存在密码的配置位置。
- 主按钮：去采集资产。
- 次按钮：刷新资产状态。

“去采集资产”跳转到资产采集页面，或打开现有资产采集任务创建抽屉。

### 5.3 顶部筛选和操作

字段：

| 控件 | 类型 | 默认值 | 说明 |
|:---|:---|:---|:---|
| 主机范围 | 下拉/选择器 | 全部主机 | 支持主机组、指定主机 |
| 应用类型 | 多选 | 全部 | 数据库、中间件、Web 服务、AI 应用、MCP 服务、LLM 网关 |
| Agent 状态 | 分段控件 | 在线 | 在线、全部 |
| 置信度 | 多选 | 高、中 | 高、中、低 |
| 关键字 | 输入框 | 空 | 搜索应用名、主机名、IP |

操作：

- 一键分析资产应用。
- 刷新。
- 查看资产采集状态。

### 5.4 分析结果表

字段：

| 字段 | 说明 |
|:---|:---|
| 主机 | 主机名、IP、在线状态 |
| 应用 | 应用名称、版本、类型 |
| 资产来源 | 应用资产记录及其关联的进程、端口、软件信息 |
| 可能密码位置 | 配置路径、systemd unit、环境文件、认证文件 |
| 凭据类型 | 明文、hash、salted hash、auth string、unknown |
| AI 置信度 | 高、中、低 |
| 风险说明 | 为什么认为该应用可能存在密码 |
| 最近检查 | 从未检查、最近任务状态、最近命中数 |
| 操作 | 检查弱密码、查看分析依据、忽略 |

### 5.5 分析依据抽屉

点击“查看分析依据”打开抽屉：

- 应用资产原始摘要。
- 关联进程命令行。
- 关联端口。
- 已知配置路径。
- LLM 判断原因。
- 推荐 Profile。
- 预计 extractor。

抽屉中不展示任何密码、hash、salt、token。

### 5.6 单应用检查入口

每行应用提供“检查弱密码”按钮。点击后打开检查确认抽屉：

- 目标主机。
- 目标应用。
- 预计读取的配置路径和字段。
- 预计凭据格式。
- Agent 在线状态。
- 字典策略。
- AI 匹配策略。

用户确认后调用 `POST /api/v1/weak-password/tasks/by-application` 创建任务。

## 6. 弱密码检查页

### 6.1 主流程

```text
选择应用
  ↓
确认配置采集计划
  ↓
Agent 获取配置
  ↓
服务端明文/加密密码匹配
  ↓
结果展示
```

### 6.2 创建检查抽屉

字段：

| 字段 | 控件 | 说明 |
|:---|:---|:---|
| 检查对象 | 只读 | 单个应用，也支持批量应用扩展 |
| 默认 1000 字典 | 开关 | 默认开启 |
| 上传字典 | 多选 | 可选用户上传字典 |
| AI 生成字典 | 开关/按钮 | 可直接进入生成流程 |
| 混合规则 | 开关 | 年份、特殊字符、大小写、账号/应用拼接 |
| 模糊规则 | 开关 | leet、拼音、近似字符 |
| 加密/hash LLM 匹配 | 开关 | 受管理员策略控制 |
| 读取配置失败时 AI 修复 | 开关 | 默认开启 |

### 6.3 任务进度条

任务详情页顶部展示阶段进度条：

| 阶段 | 说明 | 进度建议 |
|:---|:---|:---|
| 资产应用分析 | LLM 基于应用资产生成可采集应用和配置位置 | 0-15 |
| 下发 Agent 工具 | server 通过 `ExecuteTool` 下发 `WeakPassword.CollectCredentials` | 15-25 |
| 获取配置文件 | Agent 读取指定文件和字段 | 25-45 |
| AI 修复定位 | 配置读取失败时，LLM 调用受控辅助工具继续定位 | 45-65 |
| 密码匹配 | 明文由服务端匹配，加密/hash 由 LLM 匹配并服务端校验 | 65-90 |
| 结果入库 | 写入 finding、错误和 AI 分析摘要 | 90-100 |

进度展示：

- 总进度百分比。
- 当前阶段。
- 当前主机和应用。
- 已调用 Agent 工具次数，例如 `4/10`。
- 最近一次 Agent 工具名称。
- 最近一次失败原因。
- 预计剩余时间，不足以估算时显示“计算中”。

### 6.4 10 次 Agent 工具调用上限

当大模型为了获取配置文件而调用 Agent 辅助工具时，前端必须展示调用次数。若累计调用 10 次仍未获得有效配置文件：

- 任务状态：失败。
- 错误码：`config_discovery_failed`。
- 错误说明：AI 已尝试 10 次受控 Agent 工具调用，仍未定位到有效配置文件。
- 展示已尝试路径、工具调用记录和失败原因。
- 提供操作：重试、修改范围、查看资产采集建议。

## 7. 字典管理页

### 7.1 默认 1000 弱密码字典

系统内置 1000 条默认弱密码字典。列表展示：

- 字典名称：默认弱密码字典。
- 条数：1000。
- 分类：通用弱口令、默认口令、数据库默认口令、中间件默认口令、AI 应用常见弱口令、企业组合模式。
- 状态：启用、停用。
- 操作：查看摘要、启用、停用、复制为自定义字典。

默认字典详情页只展示摘要、分类和样例数量。查看完整字典需要字典管理权限。

### 7.2 AI 一键生成字典

字典管理页提供“AI 一键生成字典”按钮。点击后打开生成抽屉。

输入项：

| 字段 | 说明 |
|:---|:---|
| 生成目标 | 通用、指定应用、指定主机、指定账号模式 |
| 应用类型 | Redis、MySQL、PostgreSQL、Nginx Basic Auth、AI Agent、MCP Server、LLM Gateway |
| 组织关键词 | 公司简称、系统名、环境名、业务线 |
| 账号关键词 | admin、root、service、应用账号名 |
| 生成数量 | 默认 200，最大 1000 |
| 规则 | 年份后缀、特殊字符、大小写、拼音、leet、应用名组合、主机名组合 |
| 去重策略 | 与默认字典去重、与上传字典去重 |

生成结果页：

- 候选数量。
- 规则分布。
- 风险等级分布。
- 搜索、删除、批量删除。
- 保存为“任务临时字典”或“自定义字典”。

限制：

- 不允许生成超过管理员配置的最大条数。
- 不允许把完整字典写入普通日志。
- 保存字典需要记录创建人、提示词摘要、模型、生成时间和规则配置。

## 8. 检测结果页

### 8.1 命中结果表

| 字段 | 说明 |
|:---|:---|
| 主机 | 主机名、IP |
| 应用 | 应用名称、类型 |
| 账号 | 采集到的账号 |
| 凭据类型 | plaintext、hash、salted_hash、auth_string |
| 命中密码 | 默认展示脱敏值 |
| 匹配方式 | 默认字典、上传字典、AI 生成字典、混合、模糊 |
| 状态 | confirmed、ai_inferred_needs_confirm、verify_failed |
| 置信度 | LLM 或服务端匹配置信度 |
| 配置来源 | 文件路径和字段名 |
| AI 解释 | 命中依据和风险说明 |
| 操作 | 查看详情、申请明文、复测、标记误报 |

展示规则：

- 默认展示 `matched_password_mask`。
- 用户有权限并通过审批后可查看完整 `matched_password`。
- `ai_inferred_needs_confirm` 必须显示醒目标识，不能和 confirmed 混淆。

### 8.2 采集失败表

字段：

- 主机。
- 应用。
- 失败阶段。
- 错误码。
- 最近一次 Agent 工具。
- Agent 工具调用次数。
- 已尝试配置路径。
- AI 修复建议。
- 操作。

常见错误：

| 错误码 | 页面说明 |
|:---|:---|
| `no_application_assets` | 当前范围没有应用资产，请先采集资产 |
| `agent_not_connected` | Agent 不在线，无法下发工具 |
| `permission_denied` | Agent 无权限读取配置文件 |
| `field_not_found` | 文件存在，但未找到密码字段 |
| `config_discovery_failed` | AI 已调用 10 次 Agent 工具仍未定位有效配置 |
| `llm_match_verify_failed` | AI 返回候选未通过服务端校验 |

## 9. 交互状态

| 状态 | 页面表现 |
|:---|:---|
| 无应用资产 | 空状态 + 去采集资产按钮 |
| 正在分析应用资产 | 表格 loading + 顶部进度提示 |
| 分析完成但无可采集应用 | 空状态 + 展示分析依据 |
| 可检查应用存在 | 展示应用表 + 单应用检查按钮 |
| Agent 工具执行中 | 进度条 + 当前工具 + 次数 |
| 10 次工具调用失败 | 失败态 + 已尝试工具记录 |
| 匹配完成 | 命中结果表和失败表刷新 |

## 10. 权限和审计

| 操作 | 权限 | 审计 |
|:---|:---|:---|
| 一键分析资产应用 | 弱密码查看权限 | 记录范围、用户、结果数量 |
| 发起弱密码检查 | 弱密码扫描权限 | 记录目标应用、字典策略、AI 策略 |
| AI 一键生成字典 | 字典管理权限 | 记录提示词摘要、数量、模型 |
| 查看完整命中密码 | reveal 审批 | 记录审批人、查看人、时间、水印 |

## 11. 前端测试用例

- 应用资产分析页无资产时展示“先采集资产”提示和跳转按钮。
- 一键分析资产应用只展示应用资产中的可疑应用。
- 用户能从单个应用行发起弱密码检查。
- 任务进度条能展示阶段、百分比、当前应用和 Agent 工具调用次数。
- 大模型调用 10 次 Agent 工具仍未获取配置文件时展示 `config_discovery_failed`。
- 字典管理页展示默认 1000 弱密码字典摘要。
- AI 一键生成字典能配置应用、关键词、数量、规则并保存。
- 创建任务页面能选择字典、混合、模糊、AI 匹配策略。
- 结果表能显示 confirmed 与 AI 推断待确认状态。
- 采集失败列表能显示失败原因和 AI 修复过程。
- reveal 操作能触发审批并记录审计。

## 12. 验收标准

- 前端能一键分析应用资产，且只分析资产采集中的应用资产。
- 如果没有应用资产，前端提示用户先采集资产。
- 前端能列出所有可能存在密码的应用，并支持按单个应用发起弱密码检查。
- 任务详情能展示获取配置、AI 修复定位、密码匹配和结果入库进度条。
- 大模型累计调用 10 次 Agent 辅助工具仍未获取配置文件时，页面展示失败原因。
- 字典管理能展示默认 1000 条弱密码字典摘要。
- 前端提供 AI 一键生成字典能力，并支持保存为任务字典或自定义字典。
