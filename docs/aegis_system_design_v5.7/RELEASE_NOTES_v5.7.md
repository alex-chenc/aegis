# Aegis V5.7 版本说明

Aegis V5.7 聚焦脚本安全审计、eBPF 运行时监控增强和 AI 智能体分析体验优化，补齐脚本生成到 Agent 执行前校验的安全闭环。

## 主要更新

- 新增「命令审计配置」，支持黑名单规则增删改查、启停和正则/精确匹配。
- 新增统一脚本审计服务，覆盖基线、漏洞、POC、自愈脚本；生成后先黑名单审计，再 AI 审计，失败最多重试 3 次。
- 新增下发前校验和 Agent 侧执行前校验，拦截脚本展示 `AUDIT_BLOCKED` 状态。
- 新增「审计日志」，记录脚本内容、命中规则、AI 分析结果和审计时间线。
- eBPF 新增文件访问、网络连接事件采集，支持敏感路径过滤、IPv4/IPv6 和 Sigma 匹配。
- AI 告警分析增强计划、工具调用、反思、纠正、总结展示，支持历史恢复、攻击溯源图和分析后自动阻断。
- 优化模型配置空状态，首次未配置模型时展示可编辑表单，不再误报系统错误。

## 修复与注意事项

修复 AI 分析 SSE 中断、历史结论恢复、process_exec 命令行误报、MITRE 显示、按钮中文发糊、登录回车提交等问题。升级后需确认审计相关表和 `AUDIT_BLOCKED` 状态迁移完成；Agent 升级后建议重构 eBPF 程序和 Agent。
