# Agent Guard 内置策略目录视图

## 问题与范围

Agent Guard 的策略弹窗当前展示的是 `agent_guard_policies` 中由控制面创建和发布的策略版本。该列表只有策略键、版本和下发状态，无法解释系统内置规则；同时“创建/发布”操作会让用户误以为 Agent Guard 的内置防护依赖手工创建策略。

本次将弹窗改为内置策略目录视图：展示随 Agent Guard 提供的只读策略族，以及每个策略关联的内置规则定义。运行时 Hook 开关继续由“智能体事件感知与防护设置”控制；内置策略目录不提供创建、编辑、发布和停用操作。

## 目标行为

- 展示两个内置策略族：智能体行为监控、智能体工具命令审计。
- 展示五个内置规则的完整可读信息：规则键/版本、中文名称、说明、行为域、默认严重级别、默认动作、推荐动作、执行位置、必需证据、允许条件、MITRE 映射和默认参数。
- 工具命令审计策略明确显示：规则命中由 API-server 基于可信工具命令事件完成，Agent eBPF 只提供关联/PID 信息。
- 页面只读，不再出现“新建策略”“发布”“待下发”等会误导用户的控制面操作。
- 规则数据继续使用现有 `/agent-guard/rules` 内置规则目录接口，后端规则定义仍是唯一事实源。

## 兼容性与验证

不修改策略表、Bundle 协议或下发链路，不影响已有历史策略和 Agent 运行状态。只改变 Agent Guard 策略弹窗的展示和操作边界；已有策略 API 保留给兼容调用方和历史数据使用。

验证覆盖内置策略分组、规则完整字段展示、空数据和前端构建。
